# LearnSelfAI - React Native/Expo Conversion Specification

## 1. Project Overview

### Application Purpose
LearnSelfAI is an AI-powered personalized course creation and learning platform that allows users to:
- Generate customized educational courses on any topic using Google Gemini AI
- Get personalized course content based on their background, experience level, and learning goals
- Convert lessons into audio format using AI text-to-speech (Murf API)
- Track progress through courses with structured modules and lessons
- Manage subscriptions with tiered pricing (FREE, PLUS, PRO, PRO MAX)

### Core Value Proposition
Instead of consuming pre-made generic courses, users get completely personalized courses tailored to their specific background, goals, and learning style - generated by AI in minutes.

### Target Platforms
- iOS 13.0+
- Android 6.0+

11. **Generating:** Show LoadingAnimation with message "Creating your personalized course..."

### 7.3 Supabase Edge Functions

**8 Edge Functions:**

1. **generate-outline**
   - Method: POST
   - Input: { topic, background, level, intensity, materials, courseId }
   - Process:
     - Call Google Gemini API with custom prompt
     - Generate course outline JSON
     - Update course.outline_json
   - Output: { outline }

2. **generate-lesson**
   - Method: POST
   - Input: { lessonId, courseContext, materials }
   - Process:
     - Fetch lesson record
     - Call Gemini API for lesson content generation
     - Update lesson.markdown_content
   - Output: { markdown_content }

3. **regenerate-lesson**
   - Method: POST
   - Input: { lessonId }
   - Process: Same as generate-lesson but overwrites existing content
   - Output: { markdown_content }

4. **update-outline**
   - Method: POST
   - Input: { courseId, outline_json }
   - Process: Update course.outline_json
   - Output: { success }

5. **generate-audio**
   - Method: POST
   - Input: { lessonId, voiceType }
   - Process:
     - Fetch lesson.markdown_content
     - Call Murf API for text-to-speech
     - Download audio file
     - Upload to Supabase Storage
     - Update lesson.audio_url and audio_status
   - Output: { audio_url }

6. **generate-course-audio**
   - Method: POST
   - Input: { courseId, voiceType }
   - Process: Generate audio for all lessons in course (batch)
   - Output: { status }

7. **polar-checkout**
   - Method: POST
   - Input: { productId, userId }
   - Process:
     - Call Polar API to create checkout session
     - Return checkout URL
   - Output: { checkoutUrl }

8. **polar-portal**
   - Method: POST
   - Input: { userId }
   - Process:
     - Fetch user's Polar customer ID
     - Generate customer portal URL
   - Output: { portalUrl }

9. **polar-webhook**
   - Method: POST
   - Input: Polar webhook payload
   - Process:
     - Verify webhook signature
     - Parse event (subscription.created, subscription.updated, etc.)
     - Update profiles table with new plan_type and audio_addon
     - Insert subscription_events record
   - Output: { received: true }

### 7.4 Row Level Security (RLS)

**All tables have RLS enabled.**

**Example Policies:**

- **profiles:** Users can view and update only their own profile
- **courses:** Users can view, insert, update, delete only their own courses
- **lessons:** Users can access lessons only from courses they own
- **user_progress:** Users can view and update only their own progress
- **notes:** Users can view, insert, update, delete only their own notes

### 8.3 useSubscription Hook

**Implementation:**
```typescript
export function useSubscription() {
  const { user, profile } = useAuth();
  const [coursesUsed, setCoursesUsed] = useState(0);
  const [isLoading, setIsLoading] = useState(true);

  // Fetch courses count
  // If plan is monthly limited (PLUS, PRO), filter by created_at >= start of month
  // If plan is FREE, count all-time courses

  const planType = profile?.plan_type || 'FREE';
  const coursesLimit = getPlanLimit(planType); // FREE: 1, PLUS: 5, PRO: 30, PRO_MAX: 999999
  const canCreateCourse = coursesUsed < coursesLimit;
  const isAudioEnabled = profile?.audio_addon || planType === 'PRO_MAX';

  return {
    planType,
    coursesUsed,
    coursesLimit,
    canCreateCourse,
    isAudioEnabled,
    isLoading,
  };
}
```

### 8.4 Helper Functions

**Plan Limits:**
```typescript
export function getPlanLimit(planType: PlanType): number {
  switch (planType) {
    case 'FREE': return 1;
    case 'PLUS': return 5;
    case 'PRO': return 30;
    case 'PRO_MAX': return 999999;
    default: return 1;
  }
}

export function isPlanMonthlyLimit(planType: PlanType): boolean {
  return planType !== 'FREE'; // FREE is lifetime limit, others are monthly
}
```

## Appendix: API Integration Details

### Google Gemini API
- **Endpoint:** Gemini 1.5 Pro or Flash
- **Use Cases:** Course outline generation, lesson content generation
- **Prompts:** Custom prompts based on user background and requirements
- **Rate Limits:** Handle 429 errors with retries

### Murf API
- **Endpoint:** Text-to-speech API
- **Use Cases:** Convert markdown lesson content to audio
- **Voice Options:** Multiple male and female voices
- **Output:** MP3 or WAV audio files

### Polar.sh API
- **Endpoints:**
  - Create checkout session
  - Get customer portal URL
  - Webhooks for subscription events
- **Products:**
  - FREE (no product, default)
  - PLUS Monthly/Yearly
  - PRO Monthly/Yearly
  - PRO MAX Monthly/Yearly
  - Audio Addon Monthly
- **Webhook Events:**
  - subscription.created
  - subscription.updated
  - subscription.cancelled
  - checkout.completed

### Supabase Storage
- **Use Cases:** Store uploaded files (PDFs, documents), audio files
- **Buckets:** course-materials, lesson-audio
- **Public URLs:** Generate public URLs for audio playback
