## 🎯 Overview

This Halloween, AWS is hosting the first-ever Kiroween hackathon. Experience how Kiro can help you build your spookiest, most creative ideas. Whether you're bringing dead tech back to life, stitching together something unexpected, or creating a UI that will give users nightmares, Kiro will partner with you every step of the way.

**Your creation will be judged on:**
- Potential Value
- Implementation of Kiro
- Creativity & Design

## 📋 Submission Requirements

### Required Elements

1. **Code Repository**
   - Must be public with an [OSI-approved open source license](https://opensource.org/licenses)
   - Must contain `/.kiro` directory at root (DO NOT add to `.gitignore`)
   - For Skeleton Crew: Must contain 2 separate repo folders

2. **Functional Application**
   - Provide URL to working application
   - Include login credentials if needed (can be in public repo)

3. **Demo Video** (max 3 minutes)
   - Upload to YouTube, Vimeo, or Facebook Video
   - Make publicly visible
   - Show the project functioning on intended platform

4. **Category Selection**
   - Identify main category and any bonus categories

5. **Kiro Usage Write-up**
   - Explain how you used Kiro features (see below)

---

## 🛠️ Kiro Features to Showcase

Document your usage of these Kiro capabilities:

### Vibe Coding
- How did you structure conversations with Kiro?
- What was the most impressive code generation?

### Agent Hooks
- What workflows did you automate?
- How did hooks improve your development process?

### Spec-Driven Development
- How did you structure your spec?
- How did it compare to vibe coding?

### Steering Docs
- How did you leverage steering to improve responses?
- What strategies made the biggest difference?

### MCP (Model Context Protocol)
- How did extending Kiro's capabilities help?
- What features would have been difficult without MCP?

## ⚖️ Judging Criteria

### Stage 1: Pass/Fail
- Does the project fit the theme?
- Does it reasonably apply required features?

### Stage 2: Scoring (Equally Weighted)

| Criteria | Description |
|----------|-------------|
| **Potential Value** | Usefulness, ease of use, accessibility, market uniqueness, UI intuitiveness, scalability |
| **Implementation** | Effective use of Kiro features, variety of features used, depth of understanding, experimentation |
| **Quality & Design** | Creativity, originality, polished design, unique resources, delightful UI experiences |
